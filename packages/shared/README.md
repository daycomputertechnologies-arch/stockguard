# Shared

Single source of truth for everything both sides need.

| File | Used by | Notes |
|---|---|---|
| `seed/*.json` | API seeder, contract seed script, demo scripts | Synthetic data only |
| `abi/DrugBatchRegistry.json` | API chain adapter | Generated by `npm run compile` |
| `deployment.json` | API chain adapter | Generated by `npm run deploy` |

`expiry_in_days` and `registered_days_ago` are **offsets**, resolved against the
moment you seed. That keeps the demo urgent no matter which day someone runs it —
never commit absolute dates that quietly go stale.

QR payload format is frozen:

```
stockguard://batch/BATCH-0001
```

Scanning **opens** an existing batch. It never creates one.
